# 后台模型下载

通用模型下载使用 WorkManager；页面内的人声分离、转码、识别和自动打轴使用统一的长任务生命周期控制器。

页面任务由统一控制器管理，页面退出时会取消任务并等待资源释放。每个任务拥有独立的取消句柄，
取消一个 FFmpeg 操作不会调用全局 `FFmpegKit.cancel()`，也不会影响其他页面的波形或媒体任务。

## 调度与失败处理

- 任务使用唯一名称和 KEEP 策略，重复点击复用已有未完成任务。
- 要求网络连接，允许 Wi-Fi 和移动网络。离线时排队等待，不立即报错。
- 超时、连接失败、DNS 失败、传输不完整以及 HTTP 408/429/5xx 可以重试。
- 最多执行 3 次（首次执行加 2 次自动重试），指数退避从 10 秒开始；实际执行时间由系统调度决定。
- 存储、权限、模型校验、证书及其他 HTTP 错误直接失败，不依赖错误文案匹配。
- 取消仍通过协程和 OkHttp 取消传播，不转换成重试。
- 页面长任务取消会先标记为 `CANCELLING`，等待原生 FFmpeg session 完成清理后再释放缓存，
  避免旧任务和新任务同时操作同一临时文件。
- 沿用临时文件清理及旧模型备份逻辑；重试重新下载，不支持断点续传。
- WorkManager 是该任务状态的持久化来源；页面恢复后重新订阅。`TaskStateStore` 只是内存中的状态镜像，不是持久化任务历史。

## 通知权限

Android 13+ 首次确认下载时，在存储授权之后申请通知权限，不在主界面启动时弹出。
拒绝通知权限不阻止下载，也不会在之后每次下载时重复申请；可在系统应用设置中重新开启通知。
权限请求中的页面重建保留待下载意图，并等待 Activity Result 返回，避免任务恢复检查抢占下载启动。

## 验证

自动检查：

```powershell
.\gradlew.bat :app:testStandardDebugUnitTest --no-daemon
.\gradlew.bat :app:assembleStandardDebug --no-daemon
git diff --check
```

`ModelDownloadRetryPolicyTest` 覆盖 HTTP 状态分类、网络错误、永久错误、取消及次数边界。

仍需设备回归：

1. Android 13+ 首次下载，分别允许和拒绝通知；两者均能继续下载，拒绝后不反复请求。
2. 存储权限与通知权限分别处于请求中时重建页面，返回后只启动一个任务。
3. 离线入队后恢复网络，页面先显示等待，随后开始下载；等待期间可以取消。
4. 下载中断网或收到临时 HTTP 错误，确认重试和最终失败提示；404、磁盘不足不自动重试。
5. 下载中切到后台、普通进程重建后返回设置，确认恢复同一任务及最终模型选择。

后台调度仍受系统配额、强制停止和前台服务限制影响；本轮未保证所有设备上的实时恢复。
